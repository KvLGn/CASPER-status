Памятка для родных
  • Что это за страница. Программа сама, каждый день, делает прогнозы на матчи НБА и «играет» на бумаге — без настоящих денег. Здесь видно, работает ли она и как идут дела.
  • Кружок вверху. 🟢 — всё работает. 🔴 — какой-то шаг не сработал или давно не запускался; ниже написано, какой. Делать ничего не нужно: программа сама пробует снова каждый час. Если красное держится больше 2 дней подряд — просто сообщите об этом, когда будет связь; ничего не ломается, и деньги не теряются (их нет).
  • Полоска «минуты GitHub». Сколько бесплатного времени на сервере потрачено за месяц. Оранжевая (больше 80%) — время заканчивается, программа может остановиться до 1-го числа. Это не страшно.
  • Таблица «Бумажный тест». «сбор: N/300 ставок» — данных пока мало, выводов нет (так будет месяцы). «проходит» — способ выглядит рабочим. «сигнал остановки» — способ, похоже, не работает. Решения принимаются только 1 января и в середине апреля; каждый день смотреть не нужно.
  • Суммы в долларах. Бумажные, не настоящие.

  • Жёлтые «Сигналы». Это предупреждения, а не сбои: ставки идут как обычно. «Отчёт о травмах → ESPN» — сайт НБА не отдал PDF, взят список ESPN; держится больше 3 дней — сообщить. «Сторож переобучения: модель отклонена» — новая модель слишком отличалась от прошлой, работает прошлая; завтра попробует снова; 3 дня подряд — сообщить. «Правила НЕ совпадают с замороженными» — кто-то изменил правила варианта: это важно, сообщить сразу. «Сложная модель не смотрела рынки N дн.» — в полдень не построился прогноз второй модели (шаг predict_complex), её варианты early12-cx пропустили день, основная модель ставит как обычно; 3 дня подряд — сообщить. «Сложная и простая модели: медиана расхождения» жёлтая — прогнозы двух моделей разошлись сильнее обычного, сложная могла сломаться; 2 дня подряд — сообщить. «Выплаты Kalshi: 0 active» и «Временные данные» — справочно, ничего делать не нужно.
  • Красная плашка «Страница не обновлялась N ч». Страницу перерисовывает только облако. Плашка значит, что облако давно не запускалось (cron-job.org, отключённые Actions, истёкший токен) — всё, что ниже, устарело. Сообщить. Жёлтый заголовок «шаг X падает N дн. подряд» — второстепенный шаг (отчёт, вторая модель) не работает несколько дней; ставки идут, но сообщить. Красная строка «прогнозов на них нет» — в игровой день модель не посчитала прогнозы, ставок не будет: сообщить сразу.
  • «Вторые модели против простой». Сложная модель (D25) и модель с приором начала сезона (D26) ставят по тем же правилам, что early12, за 10–14 ч до матча. Общие ставки у них одинаковые, разница только в ставках «только у одной». Разница в деньгах за недели почти ничего не значит: в проверке на прошлом сезоне она была в пределах случайности. Вывод — в конце сезона (D25).
  • Главное. Красное не значит «всё сломалось» и не стоит денег (ставки бумажные). Программа сама запускается снова каждый час. Чинить — только если красное держится больше суток.
  • nba_update красный. Не скачались вчерашние матчи (ESPN). Ничего: утром повторит сам. Больше 2 дней — скриншот, разберём позже.
  • kalshi_snapshot / kalshi_settle красные. Не скачались цены или итоги Kalshi. «HTTP 5xx» или «timeout» — сбой у Kalshi, ждать. «403» / «429» — нас ограничили: НЕ перезапускать вручную, ждать сутки.
  • injuries красный. Нет отчёта о травмах NBA. Ничего: варианты с защитой просто не ставят в этот час.
  • predict_* / paper_daily / paper_settle красные. Не посчитались прогнозы или бумажные ставки. Перезапустить (ниже). Повторяется 2 дня — скриншот.
  • news, polymarket, odds_api, game_lines, officials, kalshi_incentives. Архивы «на будущее», на ставки не влияют. Ничего.
  • «нет успешного запуска больше 30 ч». Шаг давно не запускался, хотя матчи идут — проверить будильник cron-job.org (ниже).
  • Перезапуск с телефона. Приложение GitHub → KvLGn/CASPER → Actions → Pipeline → последний красный запуск → Re-run jobs → Re-run failed jobs. Или Run workflow → режим evening / morning, галочка force. Через 5–10 минут обновить страницу.
  • Будильник cron-job.org. 3 задания: casper-morning (10:07 UTC), casper-midday (11:37), casper-evening (каждый час :17, 16–04 UTC). Должны быть Enabled, последние запуски — код 204. Код 401 / 403 — истёк токен casper-cron. cron-job.org может прислать письмо и выключить задание — проверь, что три задания включены; выключенное — включить снова.
  • Токены: два, сроки разные. casper-cron (будильник) — до 31.12.2026; STATUS_TOKEN (страница) — до 03.01.2027. GitHub пришлёт письмо заранее. Продлить: github.com (в браузере «версия для ПК») → аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → нужный → Regenerate → скопировать. casper-cron: в cron-job.org в каждом из 3 заданий заголовок Authorization: «Bearer <новый токен>». STATUS_TOKEN: KvLGn/CASPER → Settings → Secrets and variables → Actions → STATUS_TOKEN → Update. Пока токен страницы просрочен, страница не обновляется (старое время вверху), но запуски идут.
  • Оранжевая полоска минут GitHub. Бесплатные минуты месяца почти кончились. 1-го числа обнулятся. Если до конца месяца больше недели — в cron-job.org выключить casper-midday.
  • Kalshi или ESPN недоступны несколько дней. Ничего: программа пробует каждый запуск. Не перезапускать вручную много раз. «403» больше 3 дней — блокировка по IP, разберём позже; бумажный тест на эти дни просто остановится.
Что значат слова
  • base — перевес ≥ 3%, обе стороны, вход за последние 1–2 ч до матча (облако запускается раз в 2 ч)
  • under8 — только «меньше», перевес ≥ 8%, вход за 3–6 ч до матча
  • maker — заявка по середине цены; «Отмен.» — заявка так и не исполнилась
  • blend — вероятность — смесь модели и рынка (веса на ликвидных котировках); только рынки со спредом ≤ 6¢
  • early12 / early24 — смесь модели без травм и рынка, вход за 10–14 / 22–26 ч до матча, спред ≤ 6¢; только если прошлые матчи обеих команд уже сыграны и учтены в прогнозе
  • early12-ssp — правила early12 на модели с приором минут начала сезона (D26: сколько игрок обычно играл в первые недели прошлых сезонов)
  • early12-cx / early12-cx-maker — правила early12 на сложной модели (D25: + очки из объёма бросков); -maker — заявка по середине цены
  • early12-cx-ssp (тень) — правила early12-cx на сложной модели с приором начала сезона (D27); тень — решения записываются, ставок нет, в проверку D22 не входит
  • maker-under24 — без модели: заявка на «меньше» по середине цены за 22–26 ч до матча, если середина 40–60¢ и спред ≤ 6¢ (фанаты переплачивают за «больше», C.22); $20 на заявку
  • maker-blend-1h — смесь как заявка maker по mid за последние 1–2 ч, спред ≤ 6¢ (C.43)
  • maker-blend-thin — смесь с весами по корзине спреда как заявка maker на тонких рынках (спред > 6¢ или объём < 100), 1–12 ч до матча (C.43)
  • maker-under-po — правило maker-under24 за 1–6 ч, только плей-ин и плей-офф (C.43)
  • fg3m-maker — модель без смеси как заявка maker только на трёхочковые, 1–6 ч до матча (C.51)
  • тень — вариант решает и пишет журнал взглядов, но не ставит и не входит в D22
  • ROI — прибыль / поставленные деньги (только рассчитанные ставки)
  • CLV — цена закрытия − наша цена (в центах); CLV mid — сдвиг середины bid/ask от входа к закрытию (справочно: не видит спред и комиссию, D22)

У всех вариантов, кроме maker-under24, объём рынка на входе ≥ 100 контрактов. Деньги бумажные.
